Monitoramento de energia elétrica com ESP32, Mosquitto e Node-RED

Guia do TCC (SENAI Automação) para outras turmas montarem o mesmo sistema: um medidor Finder 7M.38 envia as grandezas elétricas, o ESP32 grava no cartão SD e publica por Wi-Fi, e o Node-RED transforma tudo em um arquivo CSV para o Excel.

  1. Finder 7M.38mede tensão, corrente, potência (RS-485)
  2. MAX3485 + ESP32lê por Modbus, grava no SD e envia por Wi-Fi
  3. Mosquittobroker MQTT: recebe e distribui as mensagens
  4. Node-REDjunta as 2 partes e monta a linha CSV
  5. Excellê o CSV e gera tabelas e gráficos

Materiais

ESP32 DevKit V1, multimedidor Finder 7M.38, módulo conversor RS-485 (MAX3485), módulo RTC DS3231, módulo MicroSD com cartão, fonte bivolt de 5 V, e um computador com Windows na mesma rede Wi-Fi do ESP32.

Instale o Node.js com as opções padrão (pede senha de administrador). Depois feche e abra o terminal e confira com node --version e npm --version.

2. Mosquitto: o broker MQTT

O ESP32 publica mensagens em tópicos e o Node-RED assina esses tópicos. Os dois nunca conversam direto: o Mosquitto fica no meio. Neste projeto os tópicos são Tcc/energia/parte1 e Tcc/energia/parte2.

  1. Instale o Mosquitto e anote a pasta de instalação (o tutorial do grupo usa C:\mosquitto).
  2. Edite o arquivo mosquitto.conf dessa pasta. A versão 2.x só aceita conexões do próprio computador por padrão, então o ESP32 precisa desta configuração (exemplo para rede de laboratório, sem senha):
listener 1883
allow_anonymous true
  1. Abra o Prompt de Comando como administrador e inicie o broker, ajustando o caminho se necessário:
mosquitto -c C:\mosquitto\mosquitto.conf -v
  1. Deixe essa janela aberta. O -v mostra o log: quando o Node-RED e o ESP32 conectarem, as mensagens aparecem ali.
  2. Descubra o IP do computador com ipconfig (campo "Endereço IPv4"). Esse número vai no código do ESP32.
  3. Se o ESP32 não conectar, libere a porta 1883 de entrada no Firewall do Windows.

3. Node-RED: montando o CSV

Em outro Prompt de Comando, instale e inicie:

npm install -g --unsafe-perm node-red
node-red

Abra http://127.0.0.1:1880 no navegador. Inicie sempre o Mosquitto antes do Node-RED; se o Node-RED abrir primeiro, ele mostra "Connection failed to broker" até o broker subir.

Configuração do broker

Nome Mosquitto Local, servidor localhost, porta 1883, ID do cliente nodered_tcc, protocolo MQTT V3.1.1, keep-alive 60, "usar sessão limpa" marcado, sem TLS.

Os 5 nós do fluxo

NóConfiguração
mqtt in "Parte 1"Servidor Mosquitto Local, assinar tópico único Tcc/energia/parte1, QoS 0, saída "um objeto JSON analisado"
mqtt in "Parte 2"Igual ao anterior, com o tópico Tcc/energia/parte2
function "Juntar CSV"Recebe os dois nós mqtt in. Guarda cada parte e só gera a linha quando as duas têm o mesmo timestamp (código abaixo)
write fileCaminho C:/TCC/monitoramento.csv, ação "adicionar ao arquivo", marcar "adicionar nova linha a cada carga útil" e "criar diretório se não existir"
debug "CSV"Mostra msg.payload na janela de depuração, só para conferir

A saída da function vai para o write file e para o debug. Clique em Deploy para ativar.

Código da function "Juntar CSV" 
// === ARMAZENA PARTES NO CONTEXTO ===
let parte1 = context.get("parte1") || null;
let parte2 = context.get("parte2") || null;
let ts1 = context.get("ts1");
let ts2 = context.get("ts2");

// === SALVA A PARTE RECEBIDA ===
if (msg.topic === "Tcc/energia/parte1" && msg.payload && msg.payload.ts) {
  context.set("parte1", msg.payload);
  context.set("ts1", msg.payload.ts);
  node.status({fill:"yellow", shape:"dot", text:"Parte 1 OK"});
}
else if (msg.topic === "Tcc/energia/parte2" && msg.payload && msg.payload.ts) {
  context.set("parte2", msg.payload);
  context.set("ts2", msg.payload.ts);
  node.status({fill:"yellow", shape:"dot", text:"Parte 2 OK"});
}
else {
  return null;
}

// === VERIFICA SE TEM AS 2 PARTES COM O MESMO TIMESTAMP ===
parte1 = context.get("parte1");
parte2 = context.get("parte2");
ts1 = context.get("ts1");
ts2 = context.get("ts2");
if (!parte1 || !parte2 || ts1 !== ts2) {
  return null; // Espera a outra parte
}

function duasCasas(v) {
  let n = parseFloat(v);
  if (isNaN(n)) return "0.00";
  return n.toFixed(2);
}

// === MONTA A LINHA CSV ===
msg.payload = [
  parte1.ts,
  duasCasas(parte1.U1), duasCasas(parte1.U2), duasCasas(parte1.U3),
  duasCasas(parte1.U12), duasCasas(parte1.U23), duasCasas(parte1.U31),
  duasCasas(parte1.I1), duasCasas(parte1.I2), duasCasas(parte1.I3), duasCasas(parte1.Iavg),
  duasCasas(parte2.P1), duasCasas(parte2.P2), duasCasas(parte2.P3), duasCasas(parte2.Pt),
  duasCasas(parte2.Q1), duasCasas(parte2.Q2), duasCasas(parte2.Q3), duasCasas(parte2.Qt),
  duasCasas(parte2.S1), duasCasas(parte2.S2), duasCasas(parte2.S3), duasCasas(parte2.St),
  duasCasas(parte2.PF1), duasCasas(parte2.PF2), duasCasas(parte2.PF3), duasCasas(parte2.PFt),
  duasCasas(parte2.ang_U1_I1), duasCasas(parte2.ang_U2_I2), duasCasas(parte2.ang_U3_I3),
  duasCasas(parte2.ang_total), duasCasas(parte2.ang_U1_U2), duasCasas(parte2.ang_U2_U3), duasCasas(parte2.ang_U3_U1),
  duasCasas(parte2.freq), duasCasas(parte2.THD_I1), duasCasas(parte2.THD_I2), duasCasas(parte2.THD_I3),
  duasCasas(parte2.THD_U1), duasCasas(parte2.THD_U2), duasCasas(parte2.THD_U3),
  duasCasas(parte2.runtime),
  duasCasas(parte2.Kwh1), duasCasas(parte2.Kwh2), duasCasas(parte2.Kvarh3), duasCasas(parte2.Kvarh4)
].join(';');

// === LIMPA O CONTEXTO ===
context.set("parte1", null);
context.set("parte2", null);
context.set("ts1", null);
context.set("ts2", null);
node.status({fill:"green", shape:"dot", text:"CSV GERADO (40+ campos)"});
return msg;

O separador é ponto e vírgula de propósito: o Excel em português usa ; para separar colunas.

4. ESP32: código e ligações

  1. Na Arduino IDE, instale o suporte à placa ESP32 e as bibliotecas RTClib, ModbusMaster, PubSubClient e ArduinoJson.
  2. No início do código, troque o nome e a senha do Wi-Fi pelos da sua rede (o ESP32 só usa rede de 2,4 GHz) e coloque em mqtt_server o IP do computador obtido no passo 2.
  3. Confira se o medidor Finder 7M.38 está configurado como o código espera: endereço Modbus 1, 38400 bps, 8 bits, sem paridade, 1 stop bit.
  4. Grave o código e abra o Monitor Serial a 115200. A cada 10 segundos aparecem as medições e a mensagem "2 PARTES JSON ENVIADAS COM SUCESSO!".
MóduloLigação no ESP32
MAX3485 (RS-485)RX ao GPIO16 e TX ao GPIO17 (Serial2); A e B do módulo vão aos terminais RS-485 do medidor
MicroSDCS no GPIO5; demais pinos nos SPI padrão do ESP32
RTC DS3231Pinos I2C padrão do ESP32 (SDA e SCL)

Se o Wi-Fi cair, o ESP32 continua gravando no cartão SD (arquivos CSV por grandeza, com data e hora) e volta a enviar quando a conexão retornar.

5. Excel: lendo o CSV

  1. Com o Node-RED rodando, confira se o arquivo C:\TCC\monitoramento.csv está crescendo.
  2. No Excel, vá em Dados > Obter Dados > De Texto/CSV, escolha o arquivo e defina o delimitador como ponto e vírgula.
  3. O arquivo não tem linha de cabeçalho. Dê nome às 46 colunas na ordem abaixo.
  4. Para atualizar sozinho: nas propriedades da consulta, marque "Atualizar a cada" e escolha os minutos. Também dá para usar uma macro.
ts;U1;U2;U3;U12;U23;U31;I1;I2;I3;Iavg;P1;P2;P3;Pt;Q1;Q2;Q3;Qt;S1;S2;S3;St;PF1;PF2;PF3;PFt;ang_U1_I1;ang_U2_I2;ang_U3_I3;ang_total;ang_U1_U2;ang_U2_U3;ang_U3_U1;freq;THD_I1;THD_I2;THD_I3;THD_U1;THD_U2;THD_U3;runtime;Kwh1;Kwh2;Kvarh3;Kvarh4

Problemas comuns

SintomaO que verificar
Node-RED mostra "Connection failed to broker"O Mosquitto não estava rodando. Inicie o broker e faça um novo Deploy.
Serial do ESP32 diz "MQTT FALHOU"IP do computador errado, ESP32 e PC em redes diferentes, porta 1883 bloqueada no firewall, ou allow_anonymous ausente no mosquitto.conf.
Todos os valores aparecem 0Ligação A/B invertida, endereço ou velocidade Modbus diferentes do medidor. Atenção: o código também devolve 0 para valores menores ou iguais a 0,1.
Faltam linhas no CSV do Node-REDA function só gera a linha se as duas partes tiverem exatamente o mesmo horário. Se elas caírem em segundos diferentes, aquele ciclo é descartado. O cartão SD guarda todas as leituras.
Datas estranhas ou arquivos sem gravar no SDConfira o RTC. O código só grava no SD se o ano do RTC for 2024 ou maior.
